# Монтирование workdir по сети

Заготовка к ЧП3. Навык будет упакован из победителя основной кампании.

## Когда использовать
Агент работает в удаленном сандбоксе, а файлы лежат у пользователя. Сеть от единиц до сотен миллисекунд RTT.

## Как использовать
```bash
python scripts/mount.py serve --root <папка пользователя> --listen 0.0.0.0:7070
python scripts/mount.py mount --server <адрес>:7070 --mountpoint /work
python scripts/mount.py bench --rtt 80 --scenario session
```
`serve` запускает серверную часть рядом с папкой. `mount` поднимает FUSE-клиент в песочнице. `bench` гоняет протокол в симуляторе на выбранном профиле и сравнивает с baseline.

## Ограничения
Протокол рассчитан на одного агента и одного пользователя. Одновременные правки одного файла с двух сторон не разрешаются. Гарантия видимости правок 1 с.
