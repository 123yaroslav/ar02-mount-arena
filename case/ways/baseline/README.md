# Baseline

Один запрос на каждую операцию агента. Клиент пересылает stat, listdir, read, create, write, truncate, mkdir, unlink и rename серверу и ждет ответа. Кэша нет, предвыборки нет, запись сразу идет на сервер. По духу это sshfs с выключенным кэшем.

Почему он стартовый кандидат. Он корректен по построению, потому что каждое чтение видит текущее состояние папки, а запись подтверждается только после сервера. Его время на экземпляре служит эталоном метрики, поэтому baseline дает 1,0 с точностью до шума процессорного времени. Любая оптимизация от него видна на кривой отдельно.

Интерфейс по контракту runner арены (`common/runner-contract.md`). `solve.py` читает пример из stdin, гоняет симулятор `mountsim` из `/assets` с протоколом из `protocol/` и печатает `{"answer": "<JSON-отчет>"}`. `solve.py` одинаков во всех кандидатах. Эволюционируют только `protocol/client.py` и `protocol/server.py`, их интерфейс описан в docstring этих файлов.
